# Code of Conduct

## Our pledge

We want this project to be a friendly, harassment-free space for everyone,
regardless of experience, identity, background, or language.

## Expected behavior

- Be respectful and constructive.
- Assume good intent and ask clarifying questions.
- Give actionable feedback about code, not about people.
- Welcome newcomers and explain unfamiliar concepts patiently.
- Respect privacy: never post another person's tokens, cookies, browser
  profiles, logs, or personal data.

## Unacceptable behavior

- Harassment, insults, discrimination, or personal attacks.
- Publishing private information without permission.
- Spam, repeated off-topic comments, or deliberate disruption.
- Encouraging misuse of automation against accounts or services.

## Scope

This code applies to issues, pull requests, discussions, and any other project
space.

## Enforcement

Maintainers may edit or remove comments and may temporarily or permanently ban
contributors who violate this code. Reports can be sent to the maintainers
through the repository's private security reporting channel.

This is a short, practical code of conduct inspired by the Contributor
Covenant.
