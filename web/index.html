Compatibility

        
Not every OpenAI feature is available — here is exactly what is and is not supported.

      

    

    

      

        
FeatureStatusNotes

        
          
Chat completions✓ SupportedSystem and multi-turn history are flattened into one Gemini prompt.

          
Chat tab✓ ReusedOne persistent Gemini tab is reused for every request; no new chat is created per request.

          
Streaming≈ SimulatedSSE chunks are sent, but this is not Gemini's real token stream.

          
Model list✓ SupportedOnly the configured model, for example gemini-web.

          
Auth✓ OptionalWhen api.api_key is set, send Bearer / x-api-key.

          
Images / vision— Not supportedText only. Image parts return HTTP 400.

          
Function calling / tools— Not supportedThe Gemini web UI has no structured tool API.

          
JSON mode≈ Prompt-onlyYou can ask for JSON in the prompt, but it is not guaranteed.

          
Official Gemini API— NoThis is browser automation, not Google's official API.

        
      

      

        
        
Unofficial & slow: changes to the Gemini web UI can break selectors. For heavy daily use, the official API is a better fit; this project is for local experiments and automation with your own login.
